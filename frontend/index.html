Session 01: Digital Sound

Synthesis, Sampling, Quantization & Digital-to-Analog Conversion (DAC)

This session demonstrates how an analog sound wave is modeled mathematically, amplified with gain control, discretized in time (ADC sampling), discretized in amplitude (quantization), and reconstructed through Zero-Order Hold (ZOH).

1. Continuous Signal Synthesis

Formula: y(t) = sin(2π · f · t)
Analog Sine Wave
Frequency (f) 5 Hz
Duration (t) 1.0 s
Signal Frequency 5 Hz
Period (T = 1/f) 0.200 s
Duration 1.0 s
Nominal Max Amp ±1.00

2. Loudness / Gain Control

Formula: y_amp(t) = gain × y(t)
Amplitude Scaling
Gain Multiplier (Volume) 2.0×
Gain Setting 2.0×
Max Absolute Amp ±2.00
Frequency Maintained Unchanged (5 Hz)

3. Sampling & Nyquist Criterion (ADC)

Nyquist-Shannon Theorem: Fs ≥ 2·f_max (Avoid Aliasing)
Nyquist Satisfied
Sampling Rate (Fs) 25 Hz
OK (Safe, No Aliasing). Discrete points capture the analog shape reliably.
Sampling Rate (Fs) 25 Hz
Nyquist Rate (2×f) 10 Hz
Sample Count 25 samples

4. Quantization (Amplitude Discretization)

Voltage Discretization: L = 2^bits Discrete Levels
ADC Discretization
Select Bit Depth (Resolution):
Bit Depth 3 bit(s)
Quantization Levels 8 levels
Step Size (Δ) Δ = 0.2857
Mean Error (MAE) MAE = 0.0820

5. Digital-to-Analog Conversion (DAC Reconstruction)

Zero-Order Hold (ZOH) holds discrete quantized sample voltage until next clock cycle
DAC Output (ZOH)
Reconstructed Bits 3 bits (8 levels)
DAC Clock Rate 25 Hz
Physical DAC Filtering Note The staircase waveform represents raw ZOH voltage. In real physical DAC chips, an analog low-pass reconstruction filter removes step harmonics, smoothing it back to continuous audio.
